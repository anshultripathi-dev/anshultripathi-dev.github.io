# Anshul Tripathi Portfolio

A responsive, dark-first personal engineering portfolio built as a lightweight static site for GitHub Pages.

## Files

- `index.html` — portfolio, styles, diagrams and interactions. No build step or JavaScript dependency is required.
- `resume.html` — print-friendly resume page with a **Print / Save as PDF** action.

## Features

- Responsive navigation, dark/light theme switch and reduced-motion support.
- Filterable technical domains and expandable project case studies.
- Selectable conceptual system architecture and a small command-limited profile terminal.
- Public project links and a static GitHub repository snapshot. Live contribution activity is intentionally left to the GitHub profile rather than simulated.

## Publish

This is the `anshultripathi-dev.github.io` GitHub Pages repository. Commit and push changes to its `main` branch; GitHub Pages serves the site from the repository.
