HOW I APPROACH A PROBLEM

I’m an Integrated M.Tech. Software Engineering student at VIT Vellore, graduating in 2028. I’m drawn to what makes software dependable beyond the screen: how services communicate, infrastructure is provisioned, networks behave and systems recover.

I enjoy working with Linux, cloud platforms, backend systems, networking, automation and security. I also explore the boundary between software and hardware through embedded systems and IoT, while expanding my understanding of machine learning and language models.

Most of my learning happens by building projects that connect these layers: a device sending telemetry to a detection engine, an application surfacing model output, or an operations tool turning system signals into an explanation.

Cybersecurity · 202601

SmartHomeCyberSecurity

A smart-home intrusion detection system combining ESP32 telemetry, threshold-based rules, Isolation Forest anomaly detection and a physical security response controller.

ESP32PythonFlaskscikit-learnHTTP / REST
System design & contributions
A first ESP32 models the home device and exposes security telemetry. A Python engine polls the endpoint, evaluates rule and anomaly signals, and classifies the state as SAFE or ATTACK. A second ESP32 drives LEDs, buzzer and OLED alerts.
  • Combines known-pattern rules with unsupervised anomaly detection.
  • Includes controlled request flooding, service probing, brute-force and sensor anomaly scenarios.
  • Separates the monitored device, analysis engine and physical response controller.

RESEARCH PROTOTYPE
Medical AI · 202602

NeuroTwin AI

An explainable multimodal 3D brain-tumor digital twin research platform for joint classification and survival-risk modeling with interactive 3D visualization.

PythonPyTorchMONAIFastAPIReact · Three.js
System design & contributions
The documented architecture combines multi-sequence MRI with clinical features using 3D CNN and Vision Transformer encoders plus cross-attention. It provides classification and survival-risk heads, explainability views, and an interactive 3D twin.
  • Joint multimodal modeling with image and clinical inputs.
  • 3D attribution and mesh visualization are part of the research prototype.
  • Not clinically validated and not intended for diagnosis or treatment.
