02 / Selected work

Things I've built.

Multi-Payload BLE HID Automation System

ESP32-based BLE HID system combining embedded firmware, physical controls and wireless HID communication for hardware-triggered input automation.

  • Five-button hardware interface and predefined HID payloads.
  • BLE HID-over-GATT and modular firmware.
  • Evaluated across Windows, macOS and Android.
  • Associated with a published Indian patent application.
ESP32BLEEmbeddedIoT

Smart Home Cybersecurity IDS

An IoT-focused intrusion detection system combining ESP32 smart-home devices, a Python cybersecurity engine, rule-based detection, machine-learning anomaly detection and a physical security response controller.

  • Collected real-time telemetry from an ESP32 smart-home device over HTTP/REST.
  • Combined threshold-based IDS rules with an Isolation Forest anomaly detector.
  • Built a decision engine that classifies the environment as SAFE or ATTACK.
  • Triggered physical alerts through a second ESP32 using LEDs, buzzer and OLED display.
